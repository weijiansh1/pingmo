# 2026-08-28 分层覆盖 MLP-SAC 短训

## 结论

本次有效试验仍未通过。Level 1/2/3 均衡训练库上的 15 个 validation 飞机-指令配对中，
13 个配对的 episode 代价高于 Raw，严格 `harm_rate=86.67%`。只有 Level 2 和 Level 3
的 doublet 各有一个配对改善，因此不启动 MoE-SAC。

本次确定性策略的动作 RMS 为 `0.1282 N`、动作总变差为 `1.5246 N`，表现为低幅干预，
但不能据此声称扩大覆盖已经改善控制效果。此前 6,000 transition 试验使用了另一份旧数据库，
两者控制指标不具备可比性。

## 当前判断

当前策略多数时候接近零修正，并在两个 doublet 配对上出现小幅改善；但 step、sine、chirp
全部受害，Raw-good 保护仍未通过。由于没有同一数据库上的短预算对照，当前试验只能作为后续
同数据扩展预算的基线。现有证据支持继续验证 MLP，不支持进入 MoE。

下一轮应保持数据库哈希、网络、奖励和物理权限不变，将预算提高到 320,000 transition、
256 个完整 episode 和 8,750 次更新，并把 validation 扩到每级 3 架、共 45 个配对。只有
严格 harm rate、连续代价和 Raw-good 动作同时继续改善，才值得讨论 reward 调整或 MoE。
