# A116 正式 G0 审计设计

## 目的

对冻结的 3,000 架 IV-A P-channel 原始飞机执行可追溯的 GJB 2874-97 图 A116
滚转速率振荡审计。此审计只评价原始飞机，不接入 RL、reference 或 oracle。

## 固定工况

- 飞行阶段组为 A/C；边界来自 `data/gjb_a116_boundary.csv`。
- 偏航操纵自由。
- 每架飞机使用保持的阶跃滚转输入。
- 对每架飞机按其荷兰滚时间常数 `T_d` 标定阶跃幅值，使
  `phi(1.7 * T_d) = 60 deg`。若目标在明确的输入搜索上界内不可达到，输出
  `input_not_achievable`，不赋 A116 等级。
- 图 A120 的滚转响应先去除螺旋模态；纯延迟只平移时间，不改变峰值，因此不改变
  `P_osc / P_av` 的取值。

## 指标提取

1. 在标定响应中找第一个局部最大滚转速率 `P1`。
2. 在 `P1` 后找第一个局部最小值 `P2`。
3. 在 `P2` 后找第二个局部最大滚转速率 `P3`。
4. 按图 A120 计算
   `(P1 + P3 - 2 P2) / (P1 + P3 + 2 P2)`。
5. `psi_p` 继续作为图 A119 允许的 `psi_beta` 代理量；仅在数字化 A116 边界域内
   判为 Level 1、Level 2 或 `above_level_2`。

若缺少完整的峰-谷-峰结构、比值分母非正、边界域外或输入目标不可达，报告明确的
`not_assessable` 状态和原因，绝不以代理值产生等级。

## 数据与输出

每架记录：plant ID、数据切分、参数、`T_d`、阶跃幅值、60 度目标误差、`P1/P2/P3`
及对应时刻、`P_osc/P_av`、`psi_p`、A116 等级或不可评估原因。

完整审计输出保存至 `results/手册G0_A116_IV-A审计.json`；图保存至
`img/手册G0_A116_IV-A原始飞机审计.png`。图中只显示已严格提取且可判级的样本，
并单列不可评估原因统计。

## 测试与验收

- 用合成波形测试峰-谷-峰提取及 A120 公式。
- 测试缺少谷值、目标输入不可达、边界域外均不产生等级。
- 做少量 plant 烟测，人工检查响应和取点图。
- 运行完整 3,000 架 G0，并检查 JSON 数量、状态统计和图。

## 非目标

本工作不修改奖励、reference、oracle、SAC、MoE 或启动 GPU 训练；G0 通过不等于
G1/G2/G3 自动通过。
