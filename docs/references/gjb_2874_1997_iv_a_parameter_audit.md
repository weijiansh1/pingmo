# GJB 2874-97 IV-A 采样参数审计

本文回答当前 `pingmo` 的 P-channel 采样量中，哪些能直接映射到
GJB 2874-97 的 IV 类、A 种飞行阶段建议边界，并记录当前等级均衡采样器。
本文不把附录建议值解释为真实机群的概率分布。

## 1. 口径和限制

- GJB 正文保留了任务、类别、飞行阶段和数值剪裁空格；附录 A 明确是参考件。下文所称
  “Level 1/2/3 边界”均是附录 A 的建议值，不是脱离型号任务合同后仍普遍有效的
  “允许采样区间”。
- 当前记录声明 `aircraft_class=IV`、`flight_phase=A`、普通（非 CO/GA）任务和杆式
  A31 假设，但这些是生成器口径，不是真实型号座舱证据。速度、高度、构形、质量、重心等
  条件仍缺失，因此不能给每架样本正式 GJB 符合性结论。
- 当前连续参数为
  `theta=[L_Fa, lambda_s, T_R, zeta_d, omega_d, R_omega, R_zeta, tau_p]`；另外先采
  `S_1s`，再反标 `L_Fa`，并派生 `omega_phi` 和 `zeta_phi`。
- 本审计针对当前单 `s` 候选模型：

```math
\frac{p}{F_{as}}=
\frac{L_{F_a}s(s^2+2\zeta_\phi\omega_\phi s+\omega_\phi^2)}
{(s-\lambda_s)(s+1/T_R)(s^2+2\zeta_d\omega_d s+\omega_d^2)}
e^{-\tau_p s}.
```

## 2. GJB 能直接约束的量

| 项目量 | GJB IV-A 建议边界 | 映射结论 | 原始页 |
| --- | --- | --- | --- |
| `T_R` | Level 1 `<=1.0 s`；Level 2 `<=1.4 s`；Level 3 `<=10 s` | 直接映射，但只有上限，没有 GJB 采样下限 | 表 A18，PDF 215／印刷 211 |
| `lambda_s` | A/C 发散螺旋倍幅时间 `T_2`：Level 1 `>=12 s`；Level 2 `>=8 s`；Level 3 `>=4 s` | 对 `lambda_s>0`，等价上限分别为 `ln(2)/12=0.057762`、`ln(2)/8=0.086643`、`ln(2)/4=0.173287 1/s`；对 `lambda_s<=0`，A19 不给负向数值范围 | 表 A19，PDF 229／印刷 225 |
| `zeta_d, omega_d` | 普通 IV-A Level 1：`zeta_d>=0.19`、`zeta_d*omega_d>=0.35 rad/s`、`omega_d>=1.0 rad/s` | 必须联合判断，不能分别当成独立允许区间 | 表 A35，PDF 303／印刷 299 |
| `zeta_d, omega_d`，IV-A 的 CO/GA 子任务 | Level 1：`zeta_d>=0.4`、`zeta_d*omega_d>=0.4 rad/s`、`omega_d>=1.0 rad/s` | 比普通 IV-A 更严格；当前生成器明确标为非 CO/GA，所以不用该行给 L1 打标 | 表 A35，PDF 303／印刷 299 |
| `zeta_d, omega_d`，所有类别/阶段 | Level 2：`zeta_d>=0.02`、`zeta_d*omega_d>=0.05 rad/s`、`omega_d>=0.4 rad/s`；Level 3：`zeta_d>=0`、不限制乘积、`omega_d>=0.4 rad/s` | 可作宽松等级边界；Level 3 的 `zeta_d=0` 不等于正常机群应采零阻尼 | 表 A35，PDF 303／印刷 299 |
| `S_1s=abs(phi(1 s))/abs(F_step)` | 杆式操纵 IV 类、A 阶段：Level 1 `<=3.38 deg/N`；Level 2 `<=5.62 deg/N`；未给 Level 3 数值 | 直接约束一秒滚转操纵灵敏度，不直接约束 `L_Fa`；当前用杆式作为显式生成假设 | 表 A31，PDF 276／印刷 272 |
| 最终端到端 `tau_e` | Level 1 `<=0.10 s`；Level 2 `<=0.20 s`；Level 3 `<=0.25 s` | 只约束从完整系统响应拟合出的等效延迟 | 表 A21，PDF 250／印刷 246 |

表 A35 还规定：当 `omega_d^2 * abs(phi/beta)_d > 20 rad/s` 时，要在表中
`zeta_d*omega_d` 最小值上增加与该耦合量有关的修正。当前 SISO P-channel 没有
`beta`，所以即使三个基础数值均过线，也不能完成这项修正检查。

## 3. GJB 没有给独立上下限的量

| 项目量 | GJB 中的处理方式 | 结论 |
| --- | --- | --- |
| `L_Fa` | 出现在滚转 LOES 增益中；标准另以滚转性能、操纵力和 `S_1s` 约束整体响应 | 没有通用的 `L_Fa` 数值上下限，不能把文献机型包络称作 GJB 范围 |
| `R_omega=omega_phi/omega_d` | 影响滚转-侧滑极零关系；A5.4.1.1.4 最终以阶跃响应的 `P_osc/P_av` 和相角评价 | 没有可独立采用的 GJB 区间 |
| `R_zeta=zeta_phi/zeta_d` | 同样通过极零位置和完整响应起作用 | 没有可独立采用的 GJB 区间 |
| `omega_phi` | 分子零点参数；与 `omega_d` 的相对位置影响 A116 响应 | 没有通用独立上下限 |
| `zeta_phi` | 分子零点参数；与 `zeta_d` 共同决定 A116 响应 | 没有通用独立上下限 |
| 当前 `tau_p` | 代码实现为输入前的纯运输 FIFO 延迟 | 不等于表 A21 的拟合 `tau_e`，因此全部样本对 A21 都应记为 `not_assessable`，而不是按 `tau_p` 数值打等级 |

对 `R_omega/R_zeta/omega_phi/zeta_phi`，本项目能做的 GJB 启发式检查是图 A116/A120：
先满足滚转、螺旋和荷兰滚前置条件，再由小阶跃响应得到 `P_osc/P_av` 与
`psi_beta`；当前无 `beta` 状态，只能使用标准讨论中允许的 `psi_p` 替代量。这是组合响应
边界，不是四个参数各自的矩形范围（图 A116：PDF 240／印刷 236；图 A120：PDF 244／
印刷 240）。A 阶段还不允许出现滚转-螺旋耦合振荡（表 A20，PDF 232／印刷 228）。

## 4. 抽样机制和控制实验常数

这些量会影响机库或后续实验，但不属于八维 `theta`，也不能混入“GJB 允许参数范围”。

| 量 | 当前实现 | GJB 映射 |
| --- | --- | --- |
| 等级建议潜变量 `q=unit[0]` | Sobol 候选按 L1/L2/L3/OOD `30%/30%/30%/10%` 建议，随后用实际派生响应重新评级 | `q` 不是动态压强，只是项目的无量纲抽样坐标 |
| 最终品质配额 | L1/L2/L3 各 `900`，OOD `300`，即 `30%/30%/30%/10%` | 覆盖设计，不是真实机群出现概率 |
| Sobol 配置 | seed `20260827`，候选数 `16384`，从中取 `3000` 个有效样本 | 复现参数；无 GJB 品质等级含义 |
| 飞行包线条件 | 未采 `V/h/Mach/alpha/n_z`、构形、质量和重心 | 这些条件本应随样本保存；当前缺失意味着这里只是低阶传函族，不是完整飞机工况族 |
| 适用条件元数据 | `ordinary_not_CO_GA`、`stick_controlled_for_A31_gate`、等效滚转操纵力输入 | 是当前生成器的显式假设，不代表已知真实驾驶舱架构 |
| 驾驶员输入尺度 | 当前命令以 `22 N` 为名义满幅 | 表 A30 对 IV-A 中央杆给出的最大力为 Level 1 `88.96 N`、Level 2 `133.50 N`、Level 3 `155.68 N`；相应建议最小增量是“启动力 + 表值的 `1/4`、`1/8`、`0`”。`22 N` 只近似 Level 1 的 `88.96/4=22.24 N` 增量，既未计启动力，也不是 GJB 指定的阶跃幅值。轮式最大力为 `177.92/266.88/311.36 N`；侧杆没有建议值（表 A30，PDF 275-276／印刷 271-272） |
| RL 修正权限 | `correction_ratio=0.3`，即名义 `22 N` 下 `±6.6 N` | 项目控制权限；GJB 没有规定这个比例 |
| 修正动作限速 | 归一化 `4 s^-1`，对应当前尺度 `26.4 N/s` | 项目约束；不是 GJB 参数范围 |
| 修正通道一阶时间常数 | `0.08 s` | 项目探索值；既不是采样周期，也不是 GJB 的拟合 `tau_e` 上限 |
| 数值时基 | 策略 `0.02 s`（50 Hz），对象 `0.005 s`（200 Hz） | 仿真实现选择；不是 GJB 给定的延迟或采样范围 |

因此，“所有参数都在 GJB 允许范围内”仍不是可成立的命题。当前做法是对有直接条款的
联合动态和响应取最差等级，对其余量使用显式的证据门和 OOD 原因。

## 5. 等级目标和重新评级

`_iv_a_candidate` 先构造带一个明确“锚点条款”的候选，再由
`classify_iv_a_quality` 对实际派生参数重新评级。

| 建议桶 | 候选构造规则 | 最终标签规则 |
| --- | --- | --- |
| L1 | `T_R`、螺旋、普通 IV-A 荷兰滚和 `S_1s` 全部满足 Level 1 | 四项均为 1 |
| L2 | 在 `T_R`、螺旋、荷兰滚、`S_1s` 中轮换一个 Level 2 锚点，其余为 Level 1 | 四项的最差等级为 2 |
| L3 | 在 `T_R`、螺旋、荷兰滚中轮换一个 Level 3 锚点；A31 没有 Level 3，所以不用 `S_1s` 构造 L3 | 四项均可评且最差等级为 3 |
| OOD | 轮换超出 A18/A19/A35、`S_1s>5.62`、结构比尾部或高运输延迟锚点 | 任一 GJB 分量无可评等级，或任一外部证据门失败 |

对 GJB 未给独立范围的量，L1-L3 只接受以下项目证据门：

| 量 | L1-L3 证据门 | 处理 |
| --- | --- | --- |
| `L_Fa` | `0.04-0.47083875` | 先按 `S_1s` 反标，再根据 IV 类力输入证据包络筛选；超出者只能进 OOD |
| `R_omega` | `0.65-1.35` | 项目证据包络，不是 GJB 边界 |
| `zeta_phi` | `0.10-0.70` | 直接采样；`R_zeta=zeta_phi/zeta_d` 只派生不独立采样 |
| `tau_p` | 候选 `0.01-0.20 s`，证据门上限 `0.25 s` | 记录为 `pure_transport_delay_before_p_channel`，不用 A21 打等级 |

`omega_phi=R_omega*omega_d` 保持为派生量。这种做法是“对联合响应等级做等额覆盖”，
不是对每个参数边际区间做相互独立的均匀分布。

## 7. 审计结论和待定决策

1. GJB 边界应用于生成后的联合动态和响应，不能把每一维独立上下限的笛卡尔积称为
   “GJB 允许机群”。
2. 当前机库已实现 L1/L2/L3 各 900 和 OOD 300；等级是生成后取 A18/A19/A35/A31 的最差可评项，不是提议标签。
3. OOD 是独立研究集，不命名为“Level 4”，也不会回流训练。
4. 当前显式采用普通 IV-A 和杆式 A31 假设；若后续改为 CO/GA 或其他操纵器，必须重新生成和评级。
5. `tau_p` 已在记录和 manifest 中声明为纯运输延迟；代码字段后续仍应迁移为 `transport_delay_s`，并另建端到端 `tau_e` 拟合。
6. `zeta_phi` 已改为直接证据采样，`R_zeta` 只派生；其大动态范围需在 SAC 输入设计中单独处理。
7. `L_Fa` 保留 `S_1s` 反标，但 L1-L3 新增了有来源的增益证据门；病态大增益不再进入 ID 机库。
8. 这些标签尚未包含 A116、高耦合荷兰滚修正、端到端 `tau_e`、飞行包线和有人评价；不能作为正式 GJB 符合性结论。
