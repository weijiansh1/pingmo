# GJB τe 首版评价（2026-10-23）

按 GJB 2874-1997 A5.4.1.1.5 / 表 A21，对滚转轴做**等效时间延迟 τe** 的首版闭环评价。

## 协议

- 对象：120 架留出（短/中/长延迟各 40，来自 `sae_delay_20261023/results_large`）；
- 策略：`raw_ft`（原始历史）、`topk4`（Top-k SAE-16）、`aux_topk4`（SAE-aux）；
- 激励：0.1–10 rad/s 对数分布的 18 分量多正弦滚转指令，每分量 1 deg/s，
  记录 180 s 闭环响应，50 Hz 采样；
- 输入/输出：\(p_c \to p\)，二阶参考模型保留在回路内（视为飞控系统的一部分）；
- 拟合：4 阶滚转 LOES（滚转 + 螺旋 + 荷兰滚）+ τe；
- 门限：幅值 VAF ≥ 0.95、相位 RMSE ≤ 10°；不过门记 `not_assessable`，不赋 A21 等级；
- 单种子、单幅值，未做多幅值线性度检查。

## 结果

| 策略 | 可评/120 | τe 中位 (s) | 短/中/长中位 (s) | 1 级 | 2 级 | 3 级 | >3 级 |
|---|---:|---:|---|---:|---:|---:|---:|
| 原始历史 | 73 | 0.073 | 0.042 / 0.127 / 0.299 | 43 | 15 | 4 | 11 |
| SAE-aux | 102 | 0.102 | 0.032 / 0.125 / 0.309 | 51 | 14 | 7 | 30 |
| Top-k SAE-16 | 0 | — | — | 0 | 0 | 0 | 0 |

- τe 随 τp 增大；长延迟可评对象的中位 τe ≈ 0.30 s，超过 A21 的 3 级上限。
- Top-k SAE-16 的闭环频响在低频段散乱/持续振荡，4 阶 LOES 的 VAF 中位 0.824、
  相位 RMSE 中位 35.1°，120 架全部未过拟合门；这是 `not_assessable`，不是 τe=0。
- SAE-aux 的可评比例更高，但可评集合内 τe 中位反而更高；这是选择效应，
  不能直接与 raw 比较。

## 稳健性

### 激励幅值（120 架 × 3 策略）

| 策略 | 可评 0.5 / 1.0 / 2.0 | τe 中位 0.5 / 1.0 / 2.0 | 共同 n | 共同集 τe 范围 |
|---|---:|---|---:|---|
| 原始历史 | 41 / 73 / 91 | 0.065 / 0.073 / 0.094 | 40 | 0.055–0.066 |
| SAE-aux | 78 / 102 / 111 | 0.111 / 0.102 / 0.127 | 75 | 0.105–0.116 |
| Top-k SAE-16 | 0 / 0 / 0 | — | 0 | — |

幅值主要改变可评比例；在三种幅值都通过拟合的共同对象上，τe 中位跨度约 0.01 s。

### 策略种子（1.0 deg/s）

| 策略 | 可评 s1 / s2 | τe 中位 s1 / s2 | 共同 n | 共同中位 s1 / s2 |
|---|---:|---:|---:|---:|
| 原始历史 | 73 / 77 | 0.073 / 0.078 | 73 | 0.073 / 0.075 |
| SAE-aux | 102 / 106 | 0.102 / 0.106 | 101 | 0.100 / 0.095 |
| Top-k SAE-16 | 0 / 0 | — | 0 | — |

Top-k SAE 在两种子、三幅值下均为 0/120 可评；时域诊断显示其低频段功率明显更高，
不是单纯的 τe 增大。

## 局限

- 单种子、单幅值、180 s 记录；
- 拟合门限是项目设定，不是 GJB 规定；
- 参考模型被计入飞控系统；
- 不构成 A21 符合性结论。
