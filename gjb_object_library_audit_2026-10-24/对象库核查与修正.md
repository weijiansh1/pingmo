这一步的思路可以保留：用与飞行品质相关的动力学参数构造对象族，训练飞控控制器，再检查控制器能否跨对象工作。滚转作为路线验证入口是合理的。当前具体问题在于对象覆盖、指标解释和控制接口；已有实验支持的是有限研究对象族上的可行性，尚不能把它扩写成完整 GJB 品质保证或广泛飞机适用性。

本次直接核对了用户提供的《GJB 2874—97 电传操纵系统飞机的飞行品质》扫描 PDF，重点查看正文 3.6、4.9、5.4，以及附录 A 的分类、LOES、A18/A19/A20/A21/A31/A35 和 A116 附近说明。PDF 共 414 页；本文件的“PDF 页”从封面起数，“印刷页”指页面下方页码，两者相差 4。原文、页面图和摘要的校验记录在 [source.json](source.json)。本次不是对全部 414 页或全部条款的符合性审定。

**最应先修的是覆盖，不是继续增加同一种对象的数量。**

对冻结 5,000 条记录的统计见 [coverage.json](coverage.json)，可用 [audit_library.py](audit_library.py) 重算。下面数字按历史标签计算；已知的两条 1 ms 灵敏度边界修正另列在逐对象修正记录中。

| 检查项 | 实际结果 | 对研究结论的影响 |
|---|---:|---|
| 参数向量是否重复 | 5,000 个互不重复 | 数据不是简单重复，但“不同”不等于“覆盖充分”。 |
| 非 OOD 数量 | 4,500，L1/L2/L3 各 1,500 | 总等级均衡。 |
| 非 OOD 的四项等级组合 | 只有 8 种 | 其中 1 种全 L1，其余只有一项变成 L2 或 L3。 |
| 全库至少两项已分级指标同时退化 | **0 / 5,000** | 没有检验慢滚转、差阻尼、较快螺旋发散等同时出现时的适应性。零点、增益和延迟仍在变化；这里的“退化”严格指四项已实现分级指标。 |
| 荷兰滚为 L2 且 ω_d≥1 rad/s | **0 / 5,000** | L2 荷兰滚只取了低频子区域；频率合格、阻尼或阻尼乘积不足的区域遗漏。 |
| 0.20<τ_p≤0.25 秒 | **0 / 5,000** | 域内采样止于 0.20，而“研究范围”写到 0.25，域外延迟从大于 0.25 开始，中间是空档。 |
| train_boundary 是否专门靠近边界 | 没有 | 它与 train_core 从同一等级池依次取点。只能叫额外训练子集，不能据此宣称已作边界加密验证。 |
| 有正螺旋极点 | 2,101 | 0.75 秒不发散不能证明长期稳定；部分对象也不应被开环稳定过滤器简单删掉。 |
| T_R>8 秒 / 荷兰滚衰减时间>8 秒 | 115 / 619 | 原 8 秒任务不足以观察所有慢过程。 |

这里理论上有 3×3×3×2=54 种已定义的分量等级组合。54 只是覆盖诊断网格，不是“所有组合都真实可实现”的证明，也不是要求真实机队均匀占据这 54 格。现在的代码先把其余指标放在一级，再挑一个指标降低等级，因此 Sobol 采样本身不能补回这些被条件逻辑排除的区域。

OOD 也需按原因报告。500 个 OOD 中，228 个有 L_Fa 范围外标记，56 个有运输延迟范围外标记，其他包括频率、螺旋、时间常数、零点比等；原因会重叠。其中 160 个只是 L_Fa 范围外。OOD 表示超出研究分布，不自动表示更差的 GJB 品质。当前 OOD 的 R_ω 两段采样还有一个实现细节：分支判断使用 u<0.5 后，没有把 u 重新缩放到 [0,1]，所以实际区间约为 [0.30,0.424] 和 [2.121,3.0]，不是名义上的 [0.30,0.60] 与 [1.50,3.0]。新 OOD 套件应明确选区间后再缩放局部变量；本次 190 对象构造样例不包含新的 OOD 套件。

**旧建库“振荡比”和“调节时间”不能继续当作品质测量值。**

建库只运行 0.75 秒。考虑运输延迟后，5,000 个对象没有一个观察到完整的一个荷兰滚周期。旧辅助函数对绝对值局部峰不足三个的情况补零，因此 4,358 个对象给出振荡比 0，641 个给出 1，仅一个为其他值。这主要反映短窗和算法定义，不能解释成“多数对象没有振荡”。旧代码已经把它标成 legacy 辅助量，但字段名仍容易被下游误用。

另外 4,999 个对象的所谓 settling_time_s 恰为末采样时刻 0.749 秒。函数返回的是最后一次超出阈值的时间，没有证明之后进入并保持在容差带内。对不同螺旋特性的持续阶跃，零值也不一定是合适的稳态目标。应明确目标、容差和最短保持时长；观察不够时标记“未确认/截断”，不能把记录结束当作完成调节。

已提供 [gjb_metric_corrections.py](gjb_metric_corrections.py)：

- 按正文 3.6 区分 ζ_d≤0.2 的三极值式与 ζ_d>0.2 的两极值式；使用有符号峰—谷，支持正负指令归一化。
- 缺少所需极值或没有去除螺旋分量时返回不可评估，不补零；仅输出振荡比，不伪造 A116 等级。
- 调节时间单独处理未进入容差、末端保持时长不足等截断情形。容差及保持时长是实验设定，不冒充 GJB 数值。

没有 β 相位时，可以先做诚实的滚转时域抑振评价：指令后的超调/残余 RMS，扰动撤除后的 RMS、峰包络和恢复时间，以及执行器饱和、用力和发散率。这足够支持当前滚转路线验证中的抑振结论，但名称应与测量内容相符。

**模型形式可以保留，但应明确它表示哪个控制接口。**

当前采用：

\[
G_\theta(s)=\frac{L_{Fa}s(s^2+2\zeta_\phi\omega_\phi s+\omega_\phi^2)}
{(s-\lambda_s)(s+1/T_R)(s^2+2\zeta_d\omega_ds+\omega_d^2)}e^{-\tau_ps}.
\]

四维状态是传递函数的实现状态，不等于物理 p、r、β、φ。极点与零点共同决定滚转中能看到多强的振荡，只有阻尼和频率等级还不够。标准正文 4.9 以及附录 A4.9 要求等效系统能够代表实际总响应，见 [PDF 19](pages/pdf_019.png) 和 [PDF 72](pages/pdf_072.png)。NASA 的同类工作也将模态特征向量与滚转/侧滑响应联系起来；[NASA-TM-110306](https://ntrs.nasa.gov/citations/19970008392) 的式 (2.15) 支持单个原点零点的滚转速率形式。

完整 PDF 还暴露了引用时必须注明的差异：[印刷 211 页的形式](pages/formula_215.png)及 212 页的阶跃模态响应，与[印刷 236 页写出的分子 s²](pages/formula_240.png)并不一致，后者延迟项的排印也不同。本次保留现有 single-s、因果负指数延迟的研究模型，依据是前述模态响应、严格真有理的速率响应结构以及 NASA 式 (2.15) 的交叉核对。不能再笼统说扫描件各处公式都完全一致；这里记录的是有依据的建模选择，不是官方勘误声明。

当前训练闭环可写为：

```mermaid
flowchart LR
    C[滚转速率指令] --> R[公共参考模型]
    R --> K[教师或学生控制器]
    K --> U[等效力增量与限幅限速]
    U --> A[新增执行机构模型]
    A --> G[运输延迟与参数化滚转对象]
    G --> P[滚转速率测量]
    P --> K
```

标准的 F_as→p 与实验的 p_cmd→p 不是同一个输入输出映射。将前者作为一个合成控制对象做方法验证是可行的；若后续从真实飞机的驾驶杆输入拟合 LOES，模型可能已包含原飞控和执行机构，必须核清边界，避免重复串入这些动态。若目标是直接输出副翼指令，应明确副翼角/力矩与等效 N 的接口，而非仅改一个变量名。相关原始文献 [Morelli 2000](https://ntrs.nasa.gov/citations/20000085030) 明确说明从驾驶操纵到响应的 LOES 包含机体与控制系统总效应。

GJB 阈值主要用于最终组合系统的品质评价。构造训练对象时可以保留差品质、较难控制的对象，这正是学习控制器要处理的情况；把不满足目标品质的对象全部删除，会回避研究问题。应分别记录对象原始动力学、控制能力/任务可达性和加控制器后的响应。
