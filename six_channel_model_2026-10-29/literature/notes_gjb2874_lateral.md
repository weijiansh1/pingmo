## 1. 横航向低阶等效系统 (LOES) 与参数定义

### 1.1 滚转速率 / 滚转角对滚转杆力 (5.4.1.1.1；PDF p.215 / 印刷 p.211)
正文 5.4.1.1.1(PDF p.32 / p.28): "等效滚转模态时间常数 T_R 不应大于下列值：___。"
附录建议值: "对以下定义的等效滚转速率传递函数，等效滚转模态时间常数 T_R 的最大值在表 A18 中给出:"

    P/F_as = K_φ(0)·[ζ_φ, ω_φ]·e^(−τ_p s) / { (1/T_s)(1/T_R)[ζ_d, ω_d] }
           = K_φ(0)(s²+2ζ_φω_φ s+ω_φ²) e^(−τ_ep s) / [ (s+1/T_s)(s+1/T_R)(s²+2ζ_dω_d s+ω_d²) ]

- "在 0.1 rad/s 到 10.0 rad/s 的频率范围内，用等效系统拟配高阶系统。"
- 表 A18 T_R 最大建议值 (s): A 种 Ⅰ、Ⅳ: 1.0 (L1) / 1.4 (L2)；A 种 Ⅱ、Ⅲ: 1.4/3.0；B 全部 1.4/3.0；C Ⅰ、Ⅱ-C、Ⅳ: 1.0/1.4；C Ⅱ-L、Ⅲ: 1.4/3.0；L3 全部 10。
- "P/F_as 传递函数中其它参数的限制在本附录的其它章条中给出。"
- 时域等价式(PDF p.216 / p.212，图 A91 附近): p(t)/δ_a(阶跃) = K_s e^(−t/T_s) + K_R e^(−t/T_R) + K_d e^(−ζ_dω_d t) cos(ω_d√(1−ζ_d²) t + φ_p)。

A5.4.1.1.4 理论基础中的写法(PDF p.240 / p.236):

    P/F_as = L_Fas · s²(s²+2ζ_φω_φ s+ω_φ²) e^(τ_ep s) / [ (s+1/T_s)(s+1/T_R)(s²+2ζ_dω_d s+ω_d²) ]   (按扫描原样)

> 注: 扫描件印的是 "s²" 和 "e^(τ s)"。量纲上 p = s·φ，且图 A118 中 φ/F_as 的分子不含 s，所以这里应为 **L_Fas·s·(…)·e^(−τ_ep s)**，看起来是排印错误。

滚转角(驾驶员闭环)，图 A118(PDF p.242 / p.238):

    φ/F_as = L_Fas (s²+2ζ_φω_φ s+ω_φ²) / [ (s+1/T_s)(s+1/T_R)(s²+2ζ_dω_d s+ω_d²) ]，驾驶员增益 K_p 构成闭环

第 3 章图 2(PDF p.14 / p.10)使用极点形式: p/δ_as|阶跃 = K(s²+2ζ_φω_φ s+ω_φ²) / [(s−λ_s)(s−λ_R)(s²+2ζ_dω_d s+ω_d²)]。

### 1.2 侧滑角对脚蹬力 (5.5.1.1.1；PDF p.302 / 印刷 p.298)
正文 5.5.1.1.1(PDF p.36 / p.32): "描述由偏航操纵输入引起的侧滑反应的等效参数应具有下列特性：___。在实际使用中可能遇到的任何大小的振荡，在座舱操纵力固持和松浮的配平飞行与机动飞行中，这些要求均应满足。"
附录: "这些参数应把偏航操纵输入引起的高阶侧滑反应拟配成如下的低阶形式后求得，拟配的频率范围从 0.1 rad/s 至 10 rad/s:"

    β/F_rp = K_β e^(−τ_eβ s) / (s² + 2ζ_dω_d s + ω_d²)          (A8)

- PDF p.303 / p.299: "未规定对 τ_eβ 的限制。"

### 1.3 β/F_as —— **GJB 未给出 LOES 形式**
GJB 只用时域表达定义 ψβ(PDF p.241 / p.237): "参数 ψβ 是荷兰滚极点和零点 ω_φ 相对位置的度量。它定义了阶跃横向操纵输入后的侧滑反应中的荷兰滚分量的相位，即":

    β_d / F_as = C_d · e^(−ζ_dω_d t) · cos( ω_d √(1−ζ_d²) t + ψβ )

β/F_as 的分子要用 5.5.2.1.2 中的 Y_CF = −N^β_δas / N^β_δrp(第 5 节)，没有单独的等效拟配要求。

### 1.4 参数定义 (第 3.6 节；PDF p.12–13 / 印刷 p.8–9；图 2、图 3 在 PDF p.14–15)
- T_d = 2π / (ω_d√(1−ζ_d²))，"荷兰滚的阻尼周期"。ω_φ、ζ_φ 是 "传递函数 φ/δ_as 的分子二项式的无阻尼自振频率 / 阻尼比"。
- **P_osc/P_av**: "偏航操纵松浮，阶跃滚转操纵指令引起的滚转速率振荡分量与滚转速率平均分量之比的度量":
  - ζ_d ≤ 0.2: P_osc/P_av = (P₁ + P₃ − 2P₂) / (P₁ + P₃ + 2P₂)
  - ζ_d > 0.2: P_osc/P_av = (P₁ − P₂) / (P₁ + P₂)
  - P₁、P₂、P₃ 分别为滚转速率的第一、第二、第三个峰值(图 2、图 3)。
- **φ_osc/φ_av**: "脚蹬松浮，脉冲滚转操纵指令引起的倾斜角振荡分量与倾斜角平均分量之比的度量"；ζ_d ≤ 0.2: (φ₁+φ₃−2φ₂)/(φ₁+φ₃+2φ₂)；ζ_d > 0.2: (φ₁−φ₂)/(φ₁+φ₂)。
- β: "重心处的侧滑角…当气流从飞机对称平面的右侧流来时，侧滑角为正，或称右侧滑。"
- **Δβ**: "对阶跃滚转操纵指令(图 2 和图 3)，发生在 2 秒钟内或荷兰滚的半个周期内出现的最大侧滑角变化量，取其较大者。"
- **k**: "'指令滚转性能'对'适用滚转性能要求'(5.4.9.1 条)之比"，k = (φ_t)指令 / (φ_t)要求。(φ_t)要求按飞机类别、飞行阶段和等级从 5.4.9.1 查(Ⅳ类见表 A25b，PDF p.262 / p.258；1797A 说明应取 **等级1** 的 φ_t 要求值)；(φ_t)指令 是在规定时间内由给定阶跃滚转指令得到的倾斜角(偏航脚蹬按 5.5.9.1 条使用)。
- **t_nβ**: 对右滚指令，侧滑反应中荷兰滚振荡达到第 n 个局部最大值的时间(左滚取第 n 个局部最小值)；阶跃输入从座舱操纵偏转到指令值一半时算起，脉冲输入从脉冲作用时间的中点算起。
- **ψβ**: "在侧滑中用余弦表示的荷兰滚振荡的相位角滞后":  **ψβ = −(360/T_d)·t_nβ + (n − 1)·360°**。算例: ψβ = −360°/3.5 × 2.95 = −303°(PDF p.13)。
- **∠p/β**: "在荷兰滚自由振荡中，滚转速率与侧滑角之间的相角。当 p 超前 β 为 0°~180° 之间时为正。"
- **|φ/β|_d**: "荷兰滚模态中，倾斜角与侧滑角包线振幅在任意时间内的比值。"
- k 算例(PDF p.13–16): Ⅳ类进场 L1，按表 A25 1 s 内 φ_t = 30°；图 2/3 中各例 k = 9.1/30 = 0.30，8.1/30 = 0.27，6.8/30 = 0.23，6.0/30 = 0.20。
- 上反效应定义(PDF p.241 / p.237): 由 ∠P/β 定义；"正上反效应"表示负的 L'_β + Y_v L'_r ≈ L'_β，其中 L'_β = [L_β + (I_xz/I_x)N_β] / [1 − I_xz²/(I_x I_z)]；"∠P/β 通常是上反效应符号的好判据"。图 A116 的两条横坐标分别对应 "P 超前 β 由 45° 到 225°(正上反)" 和 "由 225° 经 360° 至 45°(负上反)"。

### 8.1 允许的飞行品质降级 (5.8.1；PDF p.400–403)

### 8.2 模型形式 (5.8.2；PDF p.405–406 / p.401–402)
正文: "当利用有人驾驶模拟方法论证是否满足要求时，应当包括一种与飞行任务相适应的大气扰动模型。作为最低要求，大气扰动模型应当由 ___ 组成。"
建议的随机风分量为德莱顿(Dryden)形式(按扫描原样):

    φ_ug(Ω) = σ_ug² (2L_u/π) · 1/[1 + (L_uΩ)²]
    φ_vg(Ω) = σ_vg² (L_v/π) · [1 + 12(L_vΩ)²] / [1 + 4(L_vΩ)²]²
    φ_wg(Ω) = σ_wg² (L_w/π) · [1 + 12(L_wΩ)²] / [1 + 4(L_wΩ)²]²
    φ_pg(Ω) = σ_pg² (2L_p/π) · 1/[1 + (L_pΩ)²]
    φ_qg(Ω) = Ω² / [1 + ((4b/π)Ω)²] · φ_wg(Ω)
    φ_rg(Ω) = Ω² / [1 + ((3b/π)Ω)²] · φ_vg(Ω)
    σ_x² = ∫₀^∞ φ_x(Ω) dΩ，Ω = ω/V，b = 机翼翼展

- σ_u²/L_u = σ_v²/(2L_v) = σ_w²/(2L_w)；σ_pg = 1.9/√(L_w b)·σ_wg；L_p = √(L_w b)/2.6。
- 表 A50(PDF p.406 / p.402): σ_ug 轻微 0~0.9，**中等 1.5**，严重 5，极端严重 7.2 m/s。"主要工作应着眼于研究'中等'紊流的等级上"；有人驾驶模拟中常用 σ_ug = 1.35~1.5 m/s(PDF p.401、p.409)。
- 尺度长度(PDF p.406，h 为重心离地高度，h₀ = 3 m，h₁ = 533 m):
  - h ≥ 533 m: L_u = L_v = L_w = h₁
  - h₀ < h < h₁: L_u = L_v = "√(h₁²h)"(扫描原样)，L_w = h
  - h < h₀: L_u = L_v = "√(h₁²h₀)"，L_w = h₀
  - > 注: 量纲上应为**立方根** (h₁²h)^(1/3)(= MIL-F-8785B 的 145·h^(1/3) ft，h₁ = 1750 ft)。PDF p.410 / p.406 说明采用的是 8785B 的尺度模型。
- 表 A51 数字滤波器(PDF p.406)，u_g: a_u = V/L_u，u_g ← (1 − a_uT)u_g + √(2a_uT)(σ_u/σ_η)η₁；v_g: a_v = 2V/L_v；w_g: a_w = 2V/L_w；p_g: σ_p = 1.9σ_w/√(L_w b)，a_p = 2.6V/√(L_w b)；q_g: σ_q ≈ √(π/(2L_w b))σ_w，a_q = πV/(4b)，q_g ← (1 − a_qT)q_g + (π/4b)(w_g − w_g,past)；r_g: σ_r ≈ √(2π/(3L_v b))σ_v，a_r = πV/(3b)，r_g ← (1 − a_rT)r_g + (π/3b)(v_g − v_g,past)。注: p_g 只有当 √(b/L_w)·C_lp > C_lβ 时才有意义；q_g 只有当 √(πb/(8L_w))·C_mq > C_mα 时；r_g 只有当 √(πb/(6L_v))·C_nr > C_nβ 时(按扫描判读)。
- **⚠ 一致性提醒**(本笔记判断，非 GJB 原文):
  1. 按扫描式，φ_vg、φ_wg 的系数 L/π 积分后只有 σ²/2，而 φ_ug 积分为 σ²。MIL-STD-1797A(本目录 1797A PDF p.804)的同一形式系数是 **2L/π**，并配合 L_u = 2L_v = 2L_w。GJB 又写 L_u = L_v = L_w = 533 m，混用了两种约定。
  2. 建议任选一套自洽形式: (i) MIL-F-8785C 形式 φ_v = σ_v²(L_v/π)[1 + 3(L_vΩ)²]/[1 + (L_vΩ)²]²，L_u = L_v = L_w = 533 m(高空)，σ_u = σ_v = σ_w；或 (ii) 1797A 形式(2L/π，12/4 系数，L_u = 2L_v = 2L_w)。
  3. 表 A51 的 v_g、w_g 一阶滤波只是近似，截止频率 2V/L 与 1797A 表 LIV 不同。
- 风切变模型(PDF p.407): u_g = V₀cosψ₀ + (t − t₀)/(t_f − t₀)·(V_f cosψ_f − V₀cosψ₀)，v_g 同理；(V_f − V₀)/(t_f − t₀) = gΔγ < 1.0 m/s²；持续 ≥ 10 s，着陆时风切变在 15 m 高度结束；至少考虑四种情况: 减小的逆风、减小的顺风、减小的侧风、逆风到顺风；"标准的风切变分量是标准的紊流等级的一半，即 σ_ug = 0.75 m/s"。V̇_max = g(γ_max − γ₀) ≤ 1 m/s²(Δγ = 6°)(PDF p.411)。
- 离散阵风(PDF p.407–408): "1−余弦"形，V = 0 (x < 0)；V = (V_m/2)(1 − cos(πx/d_m)) (0 ≤ x ≤ d_m)；V = V_m (x > d_m)。可单独或复合使用，也可用阶跃或斜坡形。

### 8.3 阵风如何进入模型 (5.8.3；正文 PDF p.44 / p.40，附录 PDF p.411–412 / p.407–408)
"突风和紊流速度仅通过空气动力项对飞机的运动方程起作用，并且当空气动力传感器是飞机增益系统的一个部分时，突风和紊流速度对这种传感器的直接影响亦应当计入。…当结构模态有重要影响时，应考虑紊流速度的精确分布。为此，在估算空气动力和力矩时，可以认为 u_g 和 v_g 只是 x 的一元函数，而 w_g 则认为是 x 和 y 的二元函数。当结构模态影响不显著时，刚性机体反应可以由扰动速度按线性变化的均匀突风或紊流均匀穿入来计算。所谓均匀穿入是飞机以重心处的 u_g、v_g 和 w_g 来计算。紊流引起的角速度在效果上相当于飞机的角速度。"近似式(只对很低的频率精确):

    −α̇_g = q_g = ∂w_g/∂x ，  p_g = −∂w_g/∂y ，  r_g = ∂v_g/∂x

"高度在 533 m 以下，紊流速度分量 u_g、v_g 和 w_g 应按座标轴方向选取，其中 u_g 指向相对平均风速矢量，而 w_g 沿垂直方向。"(PDF p.412 / p.408)
- 5.8.4 故障状态，表 A52(PDF p.412 / p.408): 故障状态Ⅰ: 轻微 → 等级2，中等 → 等级2，严重到极端严重 → 可以改出；故障状态Ⅱ: 等级3 / 可以改出 / 不要求。
